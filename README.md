# ChapLife

Personal life-management app built with Streamlit.

## Streamlit Community Cloud
- Main file: `app.py`
- Python dependencies: `requirements.txt`

## Privacy note
Do not commit `chaplife.db`, API keys, passwords, Google credentials, health images,
financial exports, or other personal data to this public repository.

## Sync status
This deployment package gets the app online. The current app still uses a local SQLite
database. For reliable phone/computer sync and persistence across app restarts/redeploys,
move user data to a private cloud database and store credentials in Streamlit Secrets.
